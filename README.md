## 📱 Best Experience: Android & Smartwatch Setup Guide

This application is engineered and optimized for **Android flagship devices** (specifically tested on **Samsung Galaxy S24 Ultra**) running **Google Chrome**, paired with a **Samsung Galaxy Watch** (Wear OS).

### 1. Installing as a Full-Screen Native App (Android Chrome)
1. Open the live GitHub Pages URL in **Google Chrome** on Android.
2. Tap the three-dot menu (`⋮`) in the top-right corner.
3. Select **"Add to Home screen"** → **"Install app"**.
4. Launch **CaliRecomp Pro** directly from your Android app drawer. It runs in standalone full-screen mode with zero browser bars and full offline caching.

### 2. Recommended Android & Chrome Settings
* **Web Bluetooth (For Live Galaxy Watch Heart Rate):**
  * Ensure **Bluetooth** and **Location** permissions are enabled for Chrome in *Android Settings → Apps → Chrome → Permissions → Nearby devices*.
  * On your **Samsung Galaxy Watch**, enable **HR Broadcast** (or use a Wear OS BLE Heart Rate broadcast utility) before tapping **"Pair Galaxy Watch (BLE)"** inside the app's Settings tab.
* **Push Notifications & Haptic Alerts:**
  * In the app's **⚙️ Setup** tab, tap **"Enable Push & Audio Alerts"** and grant Chrome notification permissions so rest timers and heart-rate zone alerts trigger even when your screen dims.
* **Text-to-Speech (Voice Coach):**
  * Uses the native Android Google Text-to-Speech engine (`Settings → General management → Text-to-speech`) for hands-free set, rest, and warm-up audio cues.

## 🧠 Core Architecture & Engines

* **Modular Zero-Build Structure:** Divided into clean modules (`index.html`, `data.js`, `engine.js`, `app.js`, `manifest.json`, `sw.js`) for instant GitHub Pages deployment.
* **Progressive Running First:** Every training session begins with a progressive Zone 2 / Interval running block (scaling safely from 10 mins in Week 1 up to 25 mins) before compound calisthenics.
* **OpenFoodFacts + Portion Picker:** Live search of global and European supermarket foods with automatic per-gram calorie and macro calculation.
* **Dynamic Calorie-to-Exercise Auto-Adjuster:** Automatically adjusts daily running duration, rest intervals, and hypertrophy sets based on real-time food intake ($\Delta C$) and live smartwatch calorie burn.
* **Weight-Loss Trajectory & Plateau Breaker:** Tracks 7-day moving average weight alongside navel waist circumference to distinguish true fat-loss plateaus from muscle recomposition.
* **Missed-Day Smart Catch-Up Engine:** Automatically merges missed compound lifts and unburned cardio into hybrid antagonist supersets on your next training day.
* **Dual Storage Engine:** 100% offline local storage with `.JSON` physical file backup/restore and optional personal Supabase Cloud REST sync.
